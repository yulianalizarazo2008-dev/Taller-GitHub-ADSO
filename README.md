\# Taller GitHub ADSO



\## Descripción

Este repositorio corresponde al taller práctico de GitHub del programa Análisis y Desarrollo de Software (ADSO).



\## Objetivo

Aprender a utilizar Git y GitHub para gestionar proyectos de desarrollo de software, trabajar con ramas y colaborar mediante Pull Requests.
